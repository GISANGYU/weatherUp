03 · DESIGN PRINCIPLES

네 가지 원칙

  1. 01

    사용자가 무드를 선택

    7개의 날씨 버튼 중 한 번 클릭 — 그 선택이 테마와 콘텐츠를 동시에 결정

  2. 02

    단일 클래스 · 전체 전환

    body.theme-X 한 줄로 색상·분위기·콘텐츠·배경 일제히 전환

  3. 03

    셀렉터 · 상호작용의 핵심

    7테마 버튼 row 가 메인 UI — 클릭 시 히어로 · 헤더 · 배경 · 콘텐츠 일제히 동기화

  4. 04

    4축 · Daily 페이지로 하루 응축

    OOTD · Food · Activity · Music — Daily 페이지에서 한 무드의 하루로 통째 큐레이션

07 · CASCADE FLOW

클릭에서 캐스케이드까지 · 4단계

STEP 01 User Click

사용자가 7테마 셀렉터 중 한 버튼을 클릭
onClick → setTheme('rainy')

STEP 02 Context Update

WeatherContext 의 currentTheme 상태 갱신
React 가 구독자 컴포넌트 리렌더 큐에 등록

STEP 03 body.theme-X

useEffect 가 body 클래스 한 줄 교체
의미 토큰 var(--bg) · var(--accent) 일제히 재해석

STEP 04 Cascade Render

Hero · Header · 배경 캔버스 · OOTD · Food · Activity · Music
한 프레임 안에 동시 전환

외부 API 없음 · 키 없음 · 네트워크 없음
오롯이 currentTheme 한 값이 화면 전부를 결정
